# Курс: Операционные системы и среды

Репозиторий для лабораторных работ по курсу «ОС. Операционные системы и среды».

## Цели на курс
1. Изучить архитектуру современных ОС.
2. Научиться диагностировать ПК встроенными средствами Windows.
3. Освоить классификацию операционных систем.
4. Научиться оформлять технические отчёты в Markdown.
5. Освоить работу с Git и GitHub.

## Структура репозитория
- `assets/screenshots/` — скриншоты диагностики.
- `labs/lab01/` — лабораторная работа №1.
- `reports/` — отчёты (паспорт системы, типы ОС, лог ИИ).
- `scripts/` — будущие системные скрипты.

## Правила ведения
- Одна работа — отдельная папка.
- Понятные имена файлов.
- Осмысленные коммиты.
- Никаких секретов и персональных данных.

## Личные ожидания от курса
Я хочу научиться лучше понимать, как работает ОС изнутри, освоить диагностику и научиться оформлять результаты в Git. Также интересно сравнить разные типы ОС и понять, где какая применяется. Надеюсь, курс поможет в будущей профессии.
