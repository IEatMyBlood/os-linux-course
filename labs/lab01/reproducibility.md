# Воспроизводимость диагностики

1. **winver** — нажми `Win + R`, введи `winver`, Enter. Проверь редакцию, версию, сборку.
2. **Параметры** — `Win + I` → Система → О системе. Проверь процессор, RAM, тип системы.
3. **Диспетчер задач** — `Ctrl + Shift + Esc` → Производительность. Проверь ЦП, память, диск, GPU.
4. **msinfo32** — `Win + R` → `msinfo32`. Проверь ОС, процессор, RAM.
5. **PowerShell** — `Win + X` → Terminal. Безопасные команды: `systeminfo`, `Get-Process`.
